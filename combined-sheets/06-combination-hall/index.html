Reference

One item per pass

The indented lines run once for every item. The loop variable is the one item currently in hand.

Name the two layers

Use a plural name for the collection and a singular name for the loop variable: vehicles and vehicle.

A running total

Set it up before the loop, add to it inside, then read it after the loop.

Keep a pair together

When a value and the item it belongs to change together, replace both in the same if.

A loop inside a loop

The inner loop finishes completely before the outer loop moves to its next item.

One total or many?

A total for every vehicle starts inside the outer loop. A total for all vehicles starts before it.

Exercise 01

Five groups have booked the village hall this week. Each booking is a dictionary and all five sit inside a list. Hours is how long the group has the hall for.

Given

bookings = [
    {"group": "Yoga Group", "hours": 2, "confirmed": True},
    {"group": "Am-Dram Society", "hours": 3, "confirmed": False},
    {"group": "Parish Council", "hours": 1, "confirmed": True},
    {"group": "Toddler Group", "hours": 2, "confirmed": True},
    {"group": "Book Club", "hours": 4, "confirmed": False},
]

Print the group on the third booking, then the hours for that same booking, then the hours for the last one. Three lines of output.

Expected output

Parish Council
1
4
Stuck?

The first bracket picks a booking out of the list by its number. The second asks that booking for one of its fields by name. Counting starts at nought.

Exercise 02

Unconfirmed bookings can still be bumped, so the caretaker needs to know which ones those are.

Reach in for the Parish Council booking and print one sentence or the other, depending on what you find.

Expected output

Parish Council is confirmed.
Stuck?

The value stored under "confirmed" is already True or False. An if can test it as it stands, and the else catches everything it does not.

Exercise 03

The hall costs £18 for every hour booked. Unconfirmed bookings carry a £15 holding deposit on top.

Work out what the Am-Dram Society owes and print the number on its own. No sentence yet.

Expected output

69

Nothing in the data holds the amount owed. It does not exist until you work it out.

Stuck?

Work out the hourly charge first and put it in a variable of its own. The deposit is a separate decision made afterwards, and it only ever adds.

Exercise 04

The caretaker only needs to chase one group — whichever one is unconfirmed and comes first in the list. There's no need to look at anything after it.

Loop through the bookings. As soon as you find one where "confirmed" is False, print its group name and stop the loop there. Nothing after that point should run.

Here, “stop the loop” means leave the current loop as soon as the first match is found. It does not stop the whole program.

Expected output

Am-Dram Society
Stuck?

The requirement is the first matching booking, not the last. Look for the loop-control word that leaves the current loop once the match has been printed.

Still stuck?

Book Club is unconfirmed too, but it comes later. If your program reports Book Club, the loop did not stop early enough.
